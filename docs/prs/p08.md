# Phase 8 — Four bolder themes: Noor, Laal Paar, Nakshi Kantha, Patrika

Base: `v2/p07-dashboard` · Branch: `v2/p08-themes`

At the theme review the decision was to "go bolder" than Jharokha. Each new theme has its own layout for every section, plus its own photo shape, ornament set, type pairing, opening animation and three palettes (one of them dark). Three of them also add a page-level detail.

| Theme | For | Signature | Opening |
|---|---|---|---|
| **Noor** (নূর) | Muslim, modern nikah | Text-first single column. A line-drawn arch glows with lamplight around the names. Photos are small and optional, so it works without bride photos. | The arch draws itself in light and you pass through it |
| **Laal Paar** (লাল পাড়) | Hindu Bengali | Red-and-white saree borders down both page edges; a slowly turning alpona; betel-leaf portraits; events as border-edged cards; the gallery as tilted prints | Alpona draws itself on red, then blooms open |
| **Nakshi Kantha** (নকশী কাঁথা) | Every tradition (aniconic: flowers and stitches only) | A patchwork-quilt hero; stitched edges; story patches joined by a thread that sews itself as you scroll; a running stitch down the page; a quilt gallery | A stitch traces the names, then the patches fly apart |
| **Patrika** (পত্রিকা) | Every tradition | A magazine cover with masthead, issue line, contents, price tag and barcode; each event as a chapter with a drop cap and a fact box; pull quotes; gallery spreads with figure numbers; a folio down the page edge | The cover page turns |

## How it is built
- **Pluggable layouts:** `src/themes/variants.js` registers theme layouts per section (`hero`, `story`, `spotlight`, `ceremony`, `gallery`) and page frames (`paar`, `thread`, `folio`). The shared sections look the theme's variant up there, so adding a theme no longer means editing them.
- **Each theme lives in its own folder:** `src/themes/<id>/{theme.js, sections.jsx}`.
- **Gallery:** the section keeps albums, paging and the lightbox; theme gallery variants only lay out the photos.
- **Ceremony building blocks** (details, moments, carousel, verse) moved to `src/site/sections/ceremony-parts.jsx` for every theme to reuse. Detail boxes are hidden when an event has no date or venue.
- **Ornaments** (`src/themes/ornaments.jsx`):
  - photo masks: leaf, patch, dome (as well as arch);
  - a generated alpona;
  - kolka paisley and the saree band;
  - stitch line and stitched flower;
  - a light star;
  - new dividers (`light`, `paar`, `stitch`, `rule`) and monogram frames (`alpona`, `stitch`, `seal`, `light`).

  Everything is coloured by theme tokens, so palettes and AI colours apply.
- **Openings** (`src/themes/openings/more.jsx`): ArchLight, AlponaBloom, StitchUnfold, CoverTurn. All are skippable and play once per visit. With reduced motion they are skipped; draw and spin animations are stopped by the existing CSS rule.
- **Invitation:** the card, families and events follow each theme:
  - Noor: an arch of light;
  - Laal Paar: a saree-bordered card with leaf event cards;
  - Nakshi Kantha: a stitched patch with patch-shaped event cards;
  - Patrika: editorial rules.
- **Fonts** (Google, not preloaded): Italiana, Jost, Kalnia, Spectral, Fraunces, Karla, Atma (Bangla display), Bodoni Moda, Hanken Grotesk.
- **Nav:** stays on one line. Long menus (such as Bengali Hindu weddings with many events) switch to the menu button below 1536 px, and the mobile menu scrolls.
- **Other fixes:**
  - The Skip button is readable on light openings.
  - Login treats Supabase's `over_request_rate_limit` as "too many sign-ins".

## Database
No migration. The themes are new `template_id` values; the editor's **Theme & colours** panel lists them automatically.

## How to test
1. As operator, open any site and add `?theme=noor` (or `laal-paar`, `nakshi-kantha`, `patrika`). Use the preview bar to switch palettes and **Replay opening**.
2. Use the preview bar's **Invitation / Full site** switch to see both views in each theme.
3. `node scripts/seed_preview.mjs <photosDir> --slug=theme-review-hindu --tradition=hindu` gives realistic Laal Paar content.
