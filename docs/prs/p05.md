# Phase 5 — Theme engine, traditions and the first two themes

Base: `v2/p04-guest-access` · Branch: `v2/p05-theme-engine`

A site now picks a **tradition** (content: ceremonies, verses, invocation, copy) and a **theme** (visuals: layout per section, fonts, ornament, photo shapes, opening animation) independently. The old one-off components are replaced by a section renderer driven by the theme. Two themes ship here: **Cinematic** (today's look on the new engine) and **Jharokha** (Mughal arches, girih geometry, emerald and antique gold). The other four v1 themes come in Phase 8.

## What changed

**Traditions** — `src/traditions/`
- `muslim`, `hindu` (variants `bengali` default and `north-indian`), `christian`, `buddhist` and `universal` (no religious text). `general` maps to `universal`.
- Each one provides an invocation (or none), verses, ceremony presets with an explicit `rank` (replaces the regex sort), and a bilingual copy dictionary (`createCopy().t()`).
- `lib/traditions.js` is a shim over the new registry until nothing imports it.
- `SOURCES.md` lists where each verse comes from. Translations still need native or clergy review before launch.

**Theme engine** — `src/themes/`
- `defineTheme()` contract (`base.js`): palettes, AI palette policy, fonts, type (case, tracking), shape (radius, photo mask), opening, a variant per section, ornament.
- `registry.js`: `getTheme(id)` (legacy `classic` → `cinematic`), `THEME_LIST` for pickers, `themesForTradition`.
- `fonts.js`: Cormorant Garamond, Inter, Marcellus, EB Garamond, Amiri, Tiro Bangla, Galada, Hind Siliguri and Tiro Devanagari Sanskrit as CSS variables with `preload: false`, so a page only downloads the faces its theme uses.
- `ornaments.jsx`: the arch path and `#shb-arch` clip path, arch outline, khatam star, girih lattice, dividers and monogram frames, all drawn as SVG in theme colours.
- `openings/OpeningGate.jsx`: **film leader** (Cinematic) and **arch doors** (Jharokha, Bismillah on jali doors). Plays once per visit, has a Skip button, and is static with reduced motion.

**Colour** — `lib/color.js`
- Semantic roles (`--t-bg`, `--t-ink`, `--t-accent`, `--t-on-accent`, `--t-ornament`, `--t-inverse`, …) built from the 6-key palettes, exposed to Tailwind through `@theme inline` (`bg-t-bg`, `text-t-ink`, `font-t-display`, …).
- Contrast guards: body ink ≥ 7:1, muted ink and text on accent ≥ 4.5:1, accent darkened or lightened when needed. Dark palettes flip automatically.
- Per-theme AI policy: `full` (Cinematic: the photo can set the whole palette), `accents` (Jharokha: the photo only changes accents), `off`. A preset from another theme never leaks into this one.
- CSS variables only ever contain validated hex colours.

**Site renderer** — `src/site/`
- `ThemeRoot` (server) sets the variables, fonts and `data-theme` on a wrapper; `ThemeRuntime` wraps motion in `MotionConfig reducedMotion="user"`.
- `SiteRenderer` builds the section list and the nav from what is enabled, so hidden sections no longer appear in the menu.
- Sections: Hero (cinematic / arch), Story (alternating / medallion), Spotlight (band / arch-split), Monogram (ring / arch), Ceremony (parallax / iwan), Gallery (masonry / arch-grid) with a new Lightbox (arrows, swipe, keyboard, focus trap), Blessings (classic / panel), Guestbook, Footer, Nav, back-to-top.
- Primitives: `Reveal`, `Photo` (masked, protected), `Bilingual`, `SacredText` (right font, `lang` and `dir` per script), `Reference` (Bangla-aware citations).
- Ceremony times are formatted in English and Bangla (`lib/dates.js`, Bangla numerals and day periods).
- Removed: VideoHero, StoryTimeline, BrideReveal, LogoReveal, CeremonySection, CinematicGallery, DuasSection, MessageBoard, old Footer and Navigation, SectionDivider, PageLoader, ParallaxSection, DynamicPalette, CustomCursor, ScrollProgress, BackToTop, `lib/animations.js`, `lib/sounds.js` and the `design-philosophy` page.

**Preview and editor**
- The couple and operators can open `/{slug}?theme=jharokha&palette=midnight-teal` to try a theme on their real site. A **preview bar** offers theme and palette chips, replay opening, and Apply. Guests never see overrides.
- The editor's **Theme & colours** panel shows theme cards, that theme's palettes plus colours from the cover photo, and the section switches.
- The Couple panel has the tradition variant (Hindu: Bengali or North Indian).

**Monogram generator** — bundled OFL fonts in `assets/fonts/` (no more `C:/Windows/Fonts`), included in the serverless bundle via `outputFileTracingIncludes`. It takes the tradition's header line and the site palette, and fits long names.

## Database
No new migration. Uses `sites.template_id`, `theme_settings` and `tradition_variant` from Phase 1.

## How to test
1. `npm run dev -- -p 3210`, sign in as the operator.
2. Open a site, **Theme & colours** → pick Jharokha and a palette → Save. Open the site: arch doors, then the arch layout.
3. As operator, add `?theme=cinematic` to the site URL to compare; use the preview bar to switch palettes and Apply.
4. Change the tradition to Universal or Hindu in **Couple & date**: no Bismillah, the ceremony order and verses follow the tradition.
5. Turn on reduced motion in the OS: the opening shows as a still frame and reveals are instant.
6. `node scripts/seed_preview.mjs <photosDir>` fills a local `theme-review` site with sample content for visual checks.
